# 🤍 Sobre o projeto

**Nosso Dia** é um álbum digital criado para preservar a história de **Natan & Marina** e transformar as memórias do casamento em uma experiência visual e interativa.

Mais do que um site tradicional, o projeto foi concebido como um **álbum contemporâneo**, reunindo fotografias, textos, momentos e pequenos detalhes da história do casal em uma única experiência.

A proposta é permitir que esse momento continue sendo revisitado ao longo do tempo, não apenas como uma coleção de fotografias, mas como uma narrativa visual.

> Uma história para ser guardada.

# ✨ A experiência

A experiência foi construída com uma abordagem de **scroll storytelling**, conduzindo o visitante por diferentes momentos da história do casal.

Fotografias, textos, tipografia, espaços de respiro, animações e transições trabalham juntos para criar um ritmo visual contínuo.

O projeto combina:

- Fotografias
- Narrativa visual
- Tipografia editorial
- Espaços negativos
- Textos e pequenas histórias
- Animações sutis
- Transições entre seções
- Galeria de memórias
- Navegação por rolagem
- Design responsivo

A proposta não é simplesmente apresentar informações, mas permitir que o visitante **percorra a história**.

---

# 📖 Estrutura do álbum

O álbum é organizado em diferentes momentos da narrativa.

### Nossa história

A abertura apresenta Natan & Marina e estabelece a identidade visual e o clima da experiência.

### História

Uma seção dedicada à trajetória do casal, aos momentos compartilhados e à construção da história que os trouxe até aqui.

### Memórias

Uma seleção de momentos que representa diferentes capítulos da vida do casal.

### Galeria

Uma experiência visual dedicada às fotografias, permitindo explorar os registros do casamento e outras memórias importantes.

# 🎞️ Conceito visual

O projeto segue uma direção **editorial, minimalista e sofisticada**, inspirada em álbuns fotográficos contemporâneos.

A interface utiliza:

- Tipografia serifada de caráter editorial
- Paleta de cores suave e sofisticada
- Fotografia como elemento principal
- Espaços negativos
- Composições assimétricas
- Hierarquia visual
- Transições delicadas
- Microinterações
- Scroll storytelling

A interface funciona como uma **moldura para as memórias**, deixando fotografias e histórias ocuparem o protagonismo.

# 🧠 UX / UI

A experiência foi planejada considerando princípios de **UX Engineering e UI Design**, buscando equilibrar estética, narrativa e facilidade de navegação.

Entre os principais conceitos utilizados estão:

# 🖼️ Galeria

A galeria é uma das partes centrais do projeto.

As fotografias são apresentadas de forma a valorizar cada imagem, preservando sua composição e evitando cortes desnecessários sempre que possível.

A experiência foi pensada para permitir que o visitante explore as fotografias com liberdade, mantendo a continuidade visual do álbum.

---

# ⚡ Performance

Como o projeto possui uma quantidade significativa de fotografias e elementos visuais, a performance é parte fundamental da experiência.

Foram considerados:

- Otimização de imagens
- Carregamento progressivo
- Lazy loading
- Redução de recursos desnecessários
- Animações eficientes
- Organização dos assets
- Responsividade
- Estabilidade durante a rolagem

O objetivo é manter a experiência visual sofisticada sem comprometer velocidade, fluidez ou estabilidade.

---

# 🌿 Filosofia do projeto

O projeto parte de uma ideia simples:

**algumas histórias merecem ser revisitadas.**

Em vez de tratar o casamento apenas como um evento, o site transforma suas fotografias e lembranças em uma experiência permanente.

A navegação foi pensada para ser contemplativa.

O visitante não precisa correr de uma informação para outra.

Ele pode simplesmente rolar, observar, lembrar e continuar.

---

# 💍 O conceito

> **Nosso futuro começa agora.**

O casamento representa um novo capítulo, mas cada fotografia preserva um pouco dos capítulos que vieram antes.

Por isso, o projeto não funciona apenas como uma galeria de imagens.

Ele funciona como uma **linha do tempo visual**, onde fotografias, textos e composição ajudam a contar a história de Natan & Marina.

---

# 🎨 Direção de design

O design busca equilibrar três elementos principais:

### História

O conteúdo conduz o visitante através dos momentos importantes do casal.

### Fotografia

As imagens são tratadas como protagonistas da experiência, com destaque para enquadramento, escala e composição.

### Interface

A interface funciona como suporte para a narrativa, utilizando tipografia, espaçamento, cores e movimento para criar ritmo e continuidade.

O resultado é uma experiência que procura se aproximar mais de um **álbum editorial interativo** do que de um site institucional tradicional.
